# Yoinks Studio v0.3.9

## Windows
- Added an Updates page with version checks, release notes, download progress, cancellation, and restart to upgrade the Setup edition.
- Updates wait until queued and active downloads finish or are cancelled.
- Portable editions link to Releases with instructions to replace the EXE while preserving the existing profile.

## Android
- Added Settings → App updates with release checks, release notes, APK download progress, cancellation, and installation through Android’s installer.
- Update APKs must match the app ID, release version and installed signing certificate, and have a higher versionCode. Size and available GitHub checksum are checked before installation.
- Updates preserve existing app storage; Android asks for permission to install from this app and confirmation to upgrade.

## Shared
- One version and release for Windows Setup, Windows Portable and Android APK.
- Windows update metadata and blockmap are included in release assets.

## Update notes
- Install this version once to get the new Updates page. Older versions do not have an updater.
- Future in-app checks need public, published GitHub releases. Do not embed repository tokens in the apps.
- Android upgrades require the same release signing key. Debug builds cannot upgrade to APKs signed with the release key.
- Windows builds remain unsigned. macOS/Linux in-app upgrades are outside this release.
