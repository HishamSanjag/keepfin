## Yoinks Studio v0.3.8

First combined release of the independent Yoinks Studio project, with Windows and Android downloads in one place.

### Windows

- Desktop interface for inspecting links and selecting video or audio formats.
- Media previews, playlist import, cancellation, retry, and download history.
- Cookies import and subtitle/metadata options.
- Readable filenames with platform folders or one shared Yoinks folder.
- Installer and portable EXE with application icons.
- Pinned original Yoinks engine with Studio's adapter changes.

### Android

- Native portrait interface with compact controls and a dark-first appearance.
- Video/audio format selection, previews, queue, and history.
- Receive text links through Android's Share menu.
- On-device downloads with a bundled native engine and media export through Android's file picker.
- APK signed with a consistent release key through GitHub Actions.

### Downloads

- **Yoinks Studio Setup 0.3.8.exe:** Windows installer.
- **Yoinks Studio Portable 0.3.8.exe:** Windows application without an installation wizard.
- **Yoinks-Studio-Android-0.3.8.apk:** Android 8.0+ on ARM64 or x86_64 devices.

### Update notes

- All downloads use version 0.3.8 and are built from the same tagged source.
- Earlier debug-signed Android APKs cannot be upgraded directly with the release-signed APK. Export downloads before replacing a debug installation: uninstalling removes files kept only in app-specific storage.
- The previous Windows desktop profile and download folder names are preserved.
- Windows downloads are currently unsigned. Automatic application updates are not implemented in this version.
