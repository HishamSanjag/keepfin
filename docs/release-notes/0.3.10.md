# Yoinks Studio v0.3.10

Public downloads and update feeds for Windows and Android, with clearer desktop update controls.

## Windows

- Moved App updates into Settings.
- Replaced raw HTTP error details with readable connection and release-feed messages.
- Pointed update checks and release links at the public downloads repository.

## Android

- Pointed update checks and APK downloads at the public downloads repository.
- Increased the version code for upgrades signed with the existing release key.

## Shared

- Release builds run in the source repository and publish one combined release to yoinks-studio-releases.
- A release becomes public after Windows installers, the signed APK and Windows update metadata finish uploading.

## Update notes

- Existing 0.3.9 installations use the private feed. Download and install 0.3.10 once manually over the existing app to switch feeds; keep your existing installation and data.
- On Android, use the release APK and the existing signing key. Debug builds cannot upgrade to a differently signed release APK.
- Subsequent versions can be checked from Settings → App updates. Android requires confirmation in its system installer; the Windows portable edition still uses manual EXE replacement.
