# Yoinks Studio v0.3.12

## Downloads that stay useful offline

- Android library artwork is saved on the device, with local video frames as a fallback. Previously cached previews remain available without an internet connection.
- Desktop library artwork is also retained locally. Temporary inspection artwork has a separate bounded cache.
- Android videos are published to **Movies/Yoinks Studio**, with dimensions and duration indexed for gallery thumbnails. Audio goes to **Music/Yoinks Studio**. Repair existing app-owned gallery entries from Settings.
- Remove individual completed, failed, or cancelled entries from history. Saved media stays in place.

## Faster, controllable inspection

- **Inspect** replaces Preview for link inspection.
- Playlist metadata is inspected with two concurrent workers and short-lived caching instead of a serial chain. Inspection can be cancelled, has explicit time limits, and preserves successful results when other links fail.
- Retry only the links that still need attention. Provider response times, authentication, and rate limits can still affect inspection.

## More polished controls

- Android menus anchor to the tapped control, match the app theme, and stay inside the available screen area.
- Expandable panels use short, restrained transitions and respect reduced-motion settings.
- Release notes are formatted in a scrollable popup in **Settings → About & updates**. Installed Android notes work offline.

## Notifications you control

- Android foreground progress, queue status, cancellation, completion, and failure notifications, with Open and Retry actions.
- Controls for individual notification categories, sound, artwork, and lock-screen privacy, plus a test notification and access to system notification settings.
- Desktop completion and failure notifications and taskbar progress have their own controls in Settings.

Install this version once to receive these changes. Future stable updates remain available through the public release feed.
