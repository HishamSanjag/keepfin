# Keepfin v1.0.2

Google Drive sign-in works on Windows. In 1.0.1 Google answered "Error 400: invalid_request" and the copy could not be added.

## Windows

- **Google Drive signs in.** Settings › Storage & copies › Add a copy › A cloud account › Google Drive opens Google's sign-in and finishes in Keepfin.
- **A sign-in that never finished no longer blocks the next one.** If the browser showed an error, or the window was closed, choosing the account again starts a fresh sign-in instead of "A sign-in is already open".

## Update notes

- Install over 1.0.1 or any earlier version, on Windows and Android. Your library, history, settings and files carry over.
- On Android nothing changes except the version number; Google Drive there already signed in through the phone.
