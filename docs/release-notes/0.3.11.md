# Yoinks Studio v0.3.11

A redesigned capture and download experience, with a new Capture Loop identity across Windows, Android and the browser preview.

## Windows

- Rebuilt Downloads around link capture, real media previews, available formats, active transfers, recoverable failures and recent saves.
- Added a searchable Library with status and video/audio filters, sorting, file details and contextual actions.
- Grouped Settings into appearance, downloads, authentication and updates; the save-location shortcut opens the relevant settings directly.
- Improved dark and light contrast, compact spacing, responsive layouts and interface scaling from 80% to 140%.
- Fixed stale preview results and partial batch recovery so failed or unsent links remain retryable without duplicating successful downloads.
- Added clearer cancellation states and history-clearing confirmation that preserves downloaded files and active work.
- Updated the desktop icon, browser favicon and touch icons with the new Capture Loop mark.

## Android

- Rebuilt the native portrait interface with compact previews, bottom navigation, an expanded-width navigation rail and controls that follow Android text sizing.
- Shared video links now preview automatically, loading metadata and format choices without pressing Preview.
- Repeated sharing refreshes the existing capture screen instead of opening another app instance.
- Completed video, audio and supported sidecar files now save automatically to the public Downloads/Yoinks Studio collection. Save a copy to… remains available for another location.
- Added collision-safe public filenames and automatic-save recovery that retains originals when storage publication fails.
- Preserved failed batch links and targeted retries after successful siblings are queued, including after Activity recreation.
- Moved app updates into Settings, added contextual file actions and improved system Back, keyboard and inset behavior.
- Added adaptive and themed Android launcher icons matching the desktop identity.

## Documentation and validation

- Added product/design guidance, competitive workflow research, platform ownership and updated build commands.
- Verified real generated video and MP3 workflows through the Windows UI and Android engine, plus batch recovery, public-save rollback and narrow-screen layouts.
- The browser remains a labelled interface preview; downloads execute in the installed Windows and Android apps.

## Downloads and upgrades

- **Setup EXE:** Windows installation and in-app updates from Settings.
- **Portable EXE:** standalone Windows application; replace the portable executable to upgrade.
- **Android APK:** signed with the existing release identity for upgrades through Android's installation confirmation.
