# Getting started

## Install

Get the latest version from the [downloads page](https://github.com/HishamSanjag/keepfin/releases/latest).

| | Pick this | Good to know |
|---|---|---|
| **Windows** | Keepfin Setup | Installs in a few clicks and updates itself quietly |
| | Portable EXE | Runs without installing. To update, replace the file with the new one |
| | MSI | For managed or company installs |
| **Android** | Keepfin APK | Needs Android 8 or later. Your phone will ask you to allow installing from your browser or file app. Updates come from inside the app |

## First start

Keepfin shows a few short pages, then asks two things:

1. **How you want to use it.** **Keepfin Complete** gives you the library, playlists and the players. **Just downloads** keeps it a plain downloader. You can change this any time in Settings.
2. **Where your Keepfin folder goes.** Everything you download is saved in this one folder. Pick the suggested place or your own. See [Your folder, copies and devices](folder-copies-devices.md).

If you used an older version, Keepfin offers to bring your library and files into the folder.

## Your first download

1. Copy a link from any app or browser.
2. Open Keepfin. It offers the copied link, or you can paste it into the box on **Downloads**.
3. Pick **Video** or **Audio** and a quality. You see each option's size before you download.
4. Tap **Download**.

On Android you can also tap **Share** in another app and choose Keepfin.

Your file appears under **Saved** on Downloads, and in your Library.
